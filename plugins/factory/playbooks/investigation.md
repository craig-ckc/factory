# Investigation

Use for a question, unexplained behavior, or uncertain cause without authorized implementation scope.

1. State the question and the evidence that would settle it.
2. Trace how the system works with [Codebase Research](../skills/codebase-research/SKILL.md); inspect historical evidence when why it works that way matters.
3. Observe the actual behavior with [UI Inspection](../skills/ui-inspection/SKILL.md) or the relevant consumer surface.
4. Test the decisive hypothesis or reproduce the issue with the smallest useful check. Use [Prototype](../skills/prototype/SKILL.md) only for a necessary isolated experiment.
5. Return grounded findings, uncertainty, and the recommended next action. Do not implement changes without scope.

Proof: inspected paths, observed behavior, and a decisive experiment when feasible; clearly distinguish facts from inference. Avoid repository tours or broad speculative risk inventories.
